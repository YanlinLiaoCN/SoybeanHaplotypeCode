# Code Description

This repository contains scripts for haplotype-based genomic analysis, specifically designed for soybean hundred-seed weight studies.

## Scripts Overview

| Script | Description |
|--------|-------------|
| `R_construct_haploblocks.R` | R script for constructing haploblocks based on linkage disequilibrium (LD) and physical distance, with a user-defined maximum number of markers per block. |
| `SNP_LLR_estimation.py` | Python script for estimating log-likelihood ratios (LLR) for individual SNP mutations of a specified length. |
| `Haplotype_LLR_estimation.py` | Python script for estimating log-likelihood ratios (LLR) for haplotypes of a specified length. |
